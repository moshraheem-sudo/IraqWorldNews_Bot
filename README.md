# نبض العراق والعالم | Iraq & World News Telegram Bot 🇮🇶🌍

بوت وقناة تليغرام آلية ومتكاملة 100% تعمل على مدار الساعة بدون أي خادم مدفوع، باستخدام **GitHub Actions**، لجلب ونشر آخر أخبار العراق والعالم العربي والدولي من أكثر من 15 مصدراً موثوقاً فور حدوثها، مع نظام ذكي لمنع تكرار أي خبر نهائياً.

---

## 🌟 المميزات الرئيسية

1. **نشر تلقائي بدون تدخل بشري:** يعمل كل 10 إلى 15 دقيقة تلقائياً عبر GitHub Actions.
2. **منع التكرار نهائياً (Deduplication):**
   - كل خبر يُعطى معرفاً فريداً (`Unique ID`) بناءً على معرّف القناة ورقم الرسالة أو رابط الخبر.
   - يتم الاحتفاظ بسجل الأخبار المرسلة داخل `data/sent_posts.json` وتحديثه تلقائياً في المستودع.
   - لا يمكن نشر أي خبر مرتين حتى لو أُعيد تشغيل البوت مئات المرات.
3. **حماية أول تشغيل (Anti-Spam First Run):**
   - عند تشغيل البوت لأول مرة، يرسل فقط آخر 3 أخبار عاجلة ويحفظ بقية الأخبار السابقة كـ "مرسلة"، لتفادي إغراق القناة بمئات الأخبار القديمة.
4. **تنسيق احترافي للمنشورات:**
   - عنوان بارز + ملخص أو نص الخبر.
   - إرفاق الصور عالية الدقة تلقائياً في حال توفرها مع الخبر.
   - رابط المصدر الأصلي لضمان الشفافية.
   - وسوم (هاشتاغات) منظمة بحسب التصنيف: `#أخبار_العراق` أو `#أخبار_العالم`.
5. **احترام حدود تليغرام (Rate Limiting):**
   - وجود فاصل زمني بين كل رسالة وأخرى لتفادي حظر البوت من قِبل تيليغرام.
   - التعامل الذكي مع خطأ `429 Too Many Requests`.

## 🚀 دليل الإعداد السريع (إضافة المفاتيح والتشغيل)

### الخطوة 1: إنشاء البوت والحصول على التوكن (`TELEGRAM_BOT_TOKEN`)
1. افتح تطبيق تليغرام وابحث عن البوت الرسمي: **[@BotFather](https://t.me/BotFather)**.
2. أرسل الأمر `/newbot`.
3. اختر اسماً للبوت، مثلاً: `نبض العراق والعالم | الإخباري`.
4. اختر معرّفاً ينتهي بـ `bot`، مثلاً: `IraqWorldNews_Bot` أو `IraqPulseNews_Bot`.
5. سيعطيك BotFather التوكن الخاص بك (API Token) على هذا الشكل:
   `7123456789:AAH...` (احفظ هذا التوكن).

### الخطوة 2: إنشاء القناة وإضافة البوت مشرفاً فيها
1. أنشئ قناة جديدة في تليغرام (عامة أو خاصة).
2. افتح إعدادات القناة -> **المشرفون (Administrators)** -> **إضافة مشرف (Add Admin)**.
3. ابحث عن اسم معرف البوت الخاص بك وأضفه.
4. تأكد من تفعيل صلاحية **نشر الرسائل (Post Messages)**.

### الخطوة 3: معرفة معرّف القناة (`TELEGRAM_CHAT_ID`)
- **إذا كانت القناة عامة ولها رابط/يوزر:** المعرف هو اليوزر مسبوقاً بعلامة `@`، مثل: `@MyNewsChannel`.
- **إذا كانت القناة خاصة:** أعد توجيه أي رسالة من قناتك إلى بوت مثل **[@userinfobot](https://t.me/userinfobot)** وسيعطيك الـ ID، وسيبدأ غالباً بـ `-100...` مثل `-1002345678901`.

### الخطوة 4: وضع المفاتيح داخل GitHub Secrets
1. أنشئ مستودعاً جديداً على حسابك في GitHub (مثلاً باسم `iraq-world-news-bot`).
2. ارفع هذا المشروع إلى المستودع.
3. داخل المستودع، اذهب إلى:
   **Settings** ⚙️ ⬅️ **Secrets and variables** ⬅️ **Actions**
4. اضغط على **New repository secret** وأضف الآتي:

| اسم السر (Secret Name) | القيمة (Value) |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توكن البوت الذي حصلت عليه من BotFather |
| `TELEGRAM_CHAT_ID` | معرّف القناة (مثال: `@MyNewsChannel` أو `-100xxxxxxxxxx`) |

### الخطوة 5: تفعيل صلاحيات الكتابة لـ GitHub Actions
1. في إعدادات المستودع، اذهب إلى:
   **Settings** ⬅️ **Actions** ⬅️ **General**
2. انزل إلى خيار **Workflow permissions**:
3. اختر: **Read and write permissions**.
4. اضغط **Save**.
*(هذه الخطوة ضرورية لكي يتمكن GitHub Actions من حفظ ملف سجل الأخبار ومنع التكرار).*

## ⏱️ آلية عمل الجدولة التلقائية

المسار موجود في `.github/workflows/telegram-news-publisher.yml`:
- يعمل تلقائياً كل 10 دقائق (`cron: "*/10 * * * *"`).
- يمكنك أيضاً تشغيله يدوياً في أي وقت من تبويب **Actions** ⬅️ **Iraq & World News Telegram Publisher** ⬅️ **Run workflow**.

## 🛠️ التشغيل والتجربة محلياً

```bash
# تثبيت المكتبات
pip install -r requirements.txt

# تجربة وهمية بدون إرسال إلى تليغرام للتأكد من جلب الأخبار
python -m bot.publisher --dry-run

# تجربة حقيقية بإرسال الأخبار إلى قناتك
python -m bot.publisher --token "YOUR_TOKEN" --chat-id "@YOUR_CHANNEL"
```
